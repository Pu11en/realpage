# RealPage Buildium

**What it is:** Buildium is an all-in-one software designed to simplify single family property management. It provides tools for accounting, leasing, maintenance, and communication to help property managers run their rental portfolios.
**Who it's for:** Property managers overseeing single family rental homes, for portfolios ranging from a handful of homes to those scaling across markets.
**Also called:** Single-Family Portfolio Management Solution, Buildium Single Family Property Management Software

**Parts of it:**
- accounting
- leasing
- maintenance
- communication
- automated rent collection
- owner disbursements
