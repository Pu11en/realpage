# RealPage Unified Platform

**What it is:** Unified Platform provides a single portal for managing all Realpage-related activities. It helps users with access control, billing, technology, online learning, and support.
**Also called:** RealPage Unity

**Parts of it:**
- User access control
- Billing
- Realpage technology innovations
- Online learning
- Support
- Realpage Authentication

**What RealPage says about it:**
- Can be configured to integrate with most OpenID & SAML identity providers.
- Realpage Multifactor Authentication will be enabled automatically for any users not using an Identity Provider at no cost.
