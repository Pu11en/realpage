# The Egg Package Delivery System Preview
The number of packages ordered by residents has doubled over the past 5 years. Today each resident receives an average of 4.5 packages per unit per month, and that number is growing. That’s a lot for your staff to manage - which is why we created The EGG.
The EGG package delivery system is an innovative package locker that frees staff from the hassle of managing packages. Couriers simply scan the package at The EGG location, place the package in The EGG and close the door. Residents are immediately notified by phone or text that a package has been delivered – the message includes a unique PIN code to pick up the package. The resident is able to retrieve the package at their convenience by entering the PIN code into the locker system.
