# Design direction (inspired by realpage.com)

- **Colors:** navy/dark blue for headers and buttons, white background, light
  gray for card/section backgrounds, teal/cyan as the accent color for
  highlights and interactive bits, charcoal gray for body text.
- **Type:** modern sans-serif, bold section headers, lighter body text,
  occasional all-caps small labels for callouts.
- **Layout feel:** clean, spaced-out, corporate-but-not-cold. Cards with
  light gray backgrounds group related info. Data/numbers presented with
  confidence (bold big numbers for stats).
- **Overall tone:** enterprise SaaS, data-heavy, "we've got this handled" —
  not playful, not cluttered.

This is style inspiration only — we're not copying realpage.com's actual
layout (it's a marketing site, not a dashboard). We're borrowing the color
palette, type feel, and "clean enterprise" tone for our own simple table
dashboard.
