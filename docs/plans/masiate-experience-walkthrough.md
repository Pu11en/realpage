# Masiate: The Complete Experience

This is the proposed finished experience, not a feature that has been built or a report of leads already found.

## 1. Open Masiate In CraneSignal

- The owner opens the regular Masiate section inside CraneSignal; it is not a separate app or a private customer area.
- The main things available are **a ranked property list, the detailed PDF and the research agent**.
- The section shows when the report was made and when the underlying records were collected, so an old report does not look freshly researched.
- The target area is Brazos, Robertson, Burleson, Grimes, Leon, Madison and Washington counties; the report says which places and sources were actually covered, rather than claiming the whole area was successfully searched.
- Proposed access behavior: the list and report are public; personal saved chat uses the existing account system, subject to verification of the real sign-in flow.

## 2. Scan The Strongest Properties

- The owner sees a short ranked list, not thousands of raw permit rows.
- Proposed summary for each property: its name or address, town, relevant work, latest supporting record date and a short reason it is worth investigating.
- Recent work that matches Masiate's services, good evidence and a usable business contact take priority; a large project budget alone does not make a better lead.
- **A possible need and an advertised open bid are labeled differently**; a permit does not prove that a buyer is looking for a contractor.
- Each summary connects to the matching PDF entry and lets the owner ask the agent about that exact property without retyping its address.
- The list and PDF use matching property identifiers and the same report edition, so similarly named buildings and separate units are not confused.
- Full searchable web profiles, map browsing, sales tracking and outreach tools are outside the chosen first version.

## 3. Read Or Download The Detailed PDF

- The PDF is the main deliverable: a carefully chosen set of top properties with as much useful, sourced information as available, not every record collected.
- There is no fixed property quota; weak entries are not added just to reach a number.
- Each entry contains the address and a map link where the location is verified; the planned or observed work; why it fits Masiate; and what remains uncertain.
- It includes known owners, developers, builders and other project participants, with their roles and available public business contact details; an architect is not automatically the hiring decision-maker.
- It includes source-backed dates, project stage, scope, known budget and relevant bid deadlines; estimated dates remain estimates, and the whole project's value is not presented as Masiate's potential earnings.
- Evidence links and document page numbers let the owner check claims, while unknown contacts, unclear status and conflicting records remain clearly marked.
- A short opening summary explains the ranking; a coverage section lists searched sources, dates and missing sources.
- The PDF is a **fixed snapshot**; later agent research does not rewrite it, and no automatic new editions or whole-report refresh are included.

## 4. Ask The Agent For More Information

- From a property summary, the owner can ask: "Why is this a good fit?", "Who owns it?", "What work is actually documented?" or "Which source says that?"
- The agent answers from the same collected records used for the PDF, with source links and dates; it does not merely guess from a property name.
- If the owner asks "Check whether this project is still moving forward," the agent can research that selected lead online using the existing tools within verified allowances.
- New findings have their own checked date and clearly distinguish what changed from what the PDF originally said; conflicting evidence is explained instead of silently replacing one claim.
- If no reliable answer is found, the agent says what is unknown and which checks failed; it does not invent a phone number, hiring intent or a construction stage.
- Research stays in that person's saved conversation; there are no separate editable lead notes.
- The agent researches only; it does not draft outreach, prepare call scripts or send messages, and Masiate's owner decides whom to contact.

## 5. Come Back To Earlier Research

- The owner should be able to return to saved research and ask about it again without recreating all the work.
- Example: after a chat finds a newer planning document, the owner later asks, "What did we find about that property's revised plans?"
- The agent should return the saved finding with its date and source, without calling an old finding current unless it rechecks it on request.
- **Chosen default after Drew delegated the detail:** reopen the original saved chat and continue there; a new chat will not automatically search other conversations.
- Reuse the existing saved-chat experience without a separate memory system or property-linked conversation routing; do not promise that merely saving messages makes every earlier finding available to the agent.
- Existing repository code documents saved sessions and an account-based chat panel; persistent storage, restored context in long chats and user identity still need verification.
- One person's conversation must never appear in another person's answers, even though the property report itself is public.
- No chat behavior changes the downloaded PDF or the public property list.

## 6. What Happens When Something Goes Wrong

- **A county website is unavailable:** record the coverage gap and continue other accessible sources; never describe failed collection as finding zero projects.
- **Few properties have strong evidence:** produce a smaller honest shortlist rather than filling the report with weak or invented opportunities; any publication threshold still belongs in the final collection plan.
- **A contact is missing:** keep the missing field explicit and explain the evidence that still makes the property promising; do not substitute an unrelated person.
- **A source charges extra:** do not purchase access, add credits or trigger unapproved overages; use an available alternative or report the gap.
- **The agent is unavailable:** the ranked list and fixed PDF remain usable, and the chat shows a retryable error instead of an invented answer.
- **The PDF is not ready:** show an honest unavailable state, not a broken download or a fake sample presented as real leads.

### Checks Before Calling This Finished

- Trace every shortlisted property to actual evidence; verify dates, addresses, contact roles and duplicate handling, including different suites or phases at one address.
- Open the section on a phone and desktop; check the ranked list, source links, PDF access and correct property context in the agent.
- Read the PDF itself for clipped text, working links, readable pages, evidence and clearly marked unknowns.
- Ask the agent a question supported by the collected data, an unanswered question and an explicit live-research question; verify its sources and dates in each case.
- Return after signing out and back in, reopen the original conversation and ask about a saved finding, including one from earlier in a long chat; repeat with a second account to prove histories stay separate.
- Test unavailable sources, empty results, exhausted allowances and chat failure without misleading the user.
- Confirm that new chat findings leave the PDF unchanged and that Masiate data does not alter CraneSignal's existing apartment leads.
- Nothing has been built, crawled, purchased or deployed during this walkthrough; source-by-source collection details and small build tasks still need to be finalized.
