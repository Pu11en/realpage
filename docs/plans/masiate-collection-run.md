# Masiate: The First Collection Run

Planning update, September 20, 2026. This specifies the run we would build; it is not a completed crawl or a list of qualified leads already found. Collection windows and operating limits below are assistant proposals, not answers attributed to Drew.

## 1. What We Will Look For

- **Outcome:** one detailed, fixed PDF of the best supported properties for Masiate, a matching ranked website preview and the same information for the research agent.
- **Area:** Brazos, Robertson, Burleson, Grimes, Leon, Madison and Washington counties, including cities and places outside city limits; a city permit system does not cover an entire county.
- **Work:** residential and commercial construction, renovations, additions and documented projects that could involve Masiate's listed trades; no apartment-only filter or minimum $3 million project value.
- **First pass:** the latest 90 days of permits and new-business signals, all currently open relevant bids, and current planning cases.
- **Backfill:** expand permits, project registrations and business-opening records to 12 months, and planning records to 24 months; older projects enter the shortlist only with evidence of continued relevance.
- Freeze the run's cutoff date when it starts and record exact requested dates for each source; missing archives shorten actual coverage, not the declared request.
- Obtain the latest available ownership record for selected candidates regardless of its age, but retain its tax year or publication date; annual ownership data is not proof of a recent sale.
- Do not promise every construction job: some repairs never produce searchable public records, and some sources require a request or account.

## 2. The Seven-County Source Checklist

**Status vocabulary:** page found, file index found, sample verified, collection tested, partial, blocked, request needed, or not yet checked. A source advances only when there is evidence for that status; no source below has passed a complete Masiate collection test.

### Brazos County

- **College Station permits:** the [weekly issued-permit page](https://www.cstx.gov/your-government/departments/planning-development-services-department/building-permits-issued/) is identified; next test is resolving its document list and checking one actual file for individual project fields.
- **College Station early projects:** the [new-development list](https://www.cstx.gov/your-government/departments/planning-development-services-department/new-development-list/) provides a separate planning source; test its files and case details rather than assuming every entry has become a permit.
- **Bryan permits:** [monthly reports](https://www.bryantx.gov/development-services/monthly-building-reports/) include summary counts; the previously inspected August report was not an address-level lead list, so test [individual permit access](https://www.bryantx.gov/development-services/online-permitting/) or prepare an export request.
- **Bryan plans:** inspect dated cases and supporting documents in the [development-review archive](https://docs.bryantx.gov/planning_development/SDRC/2026%20SDRC/); combine revisions into the same project.
- **Ownership:** [Brazos CAD certified downloads](https://brazoscad.org/certified-data-downloads/) provide a bulk-data route; validate its layout and match only appropriate real-property records.
- County-administered records and other municipalities still need separate inventory entries; Bryan plus College Station is not complete county coverage.

### Robertson County

- **Hearne:** [planning information](https://www.cityofhearne.org/217/Planning-and-Development) and the [agenda center](https://www.cityofhearne.org/AgendaCenter) are starting points; a searchable individual-permit register remains unverified.
- **Ownership:** [Robertson CAD](https://robertsoncad.com/) is the property-matching route; test individual searches before assuming bulk access.
- Add Franklin, Calvert, Bremond and county-administered development records to the discovery checklist; the [state county directory](https://comptroller.texas.gov/taxes/property-tax/county-directory/robertson.php) identifies the city taxing units, but is not itself a project feed.

### Burleson County

- **Caldwell:** its [building page](https://www.caldwelltx.gov/building) identifies Cloudpermit and permit/inspection reports; the [agenda page](https://www.caldwelltx.gov/agendas) is a second route, but anonymous project search and report downloads still need testing.
- **Outside city limits:** the [county permit page](https://www.burlesoncountytx.gov/page/living.permits) identifies the permitting route, not a verified register of issued records; prepare a register request if no public listing exists.
- **Ownership:** [Burleson CAD property search](https://esearch.burlesonappraisal.com/) exposes address, owner and property-ID searches; full automated lookup is untested.
- Include separate discovery for Somerville and Snook; do not confuse Burleson County with the City of Burleson, or Caldwell city with Caldwell County.

### Grimes County

- **Navasota:** the [city website](https://www.navasotatx.gov/) links Citizenserve planning/permits and a [project dashboard](https://navasota.maps.arcgis.com/apps/dashboards/17b7b6efb2794a54b6a2f4ce3473cb12); the dashboard required browser discovery and Citizenserve did not open reliably in this research tool, so neither is a tested collector.
- **Outside city limits:** the [county development-permit page](https://grimescountytexas.gov/floodplain_administrator) and [road department](https://grimescountytexas.gov/road-department) establish record types to investigate; forms and requirements are not individual leads.
- **Ownership:** [Grimes CAD advanced search](https://grimescad.org/Advanced-Search) is available as a search page; test address-to-parcel matching and current record access.
- Other city sources and county subdivision agendas still require discovery; cross-county projects must be matched to their actual parcel locations.

### Leon County

- **County development records:** the [floodplain/development page](https://www.co.leon.tx.us/page/leon.FloodPlain) and [subdivision information](https://www.co.leon.tx.us/page/leon.County.Judge) identify responsible offices and record types; a public issued-record register was not verified.
- The county page identifies separate city offices for Buffalo, Centerville, Jewett, Leona, Marquez, Normangee and Oakwood; inspect their permits and agendas separately instead of assuming county coverage includes them.
- **Ownership:** [Leon CAD](https://www.leoncad.org/) exposes a property search; sample lookups and any bulk download still need verification.
- Exclude Leon County, Florida results and wrongly labeled pages, even when a search result appears under a familiar domain; check the actual document's jurisdiction.

### Madison County

- **Madisonville:** [forms and permits](https://madisonvilletexas.gov/formsandpermits) and [agendas/minutes](https://madisonvilletexas.gov/agendasandminutes) are verified starting pages, not a verified project register; test agenda files and request an issued-permit export if needed.
- **Outside city limits:** the [county permits page](https://www.co.madison.tx.us/page/madison.permits) lists electric, septic, driveway and floodplain application routes; only actual records tied to relevant construction become candidate signals.
- **Ownership:** the [Madison County Tax Office](https://madisontax.org/) links [Madison CAD](https://madisoncad.org/); search access and historical coverage remain to be tested.
- Normangee needs a separate jurisdiction check; exclude Madisonville, Kentucky and other states' Madison County search results.

### Washington County

- **Brenham:** the [monthly permit archive](https://docs.cityofbrenham.org/city_government/departments/development_services/building_permits___inspections.php) lists January-August 2026 files; the August file did not resolve through the research tool, so address-level content is not verified.
- The [Brenham Accela portal](https://aca-prod.accela.com/BRENHAM/Default.aspx) describes limited anonymous information access and application search; direct access was inconsistent, so prove a sample search before relying on it.
- **Outside city limits:** [county engineering/development](https://www.co.washington.tx.us/page/washington.Road) is a separate record route to inventory; include Burton's city sources too.
- **Ownership:** [Washington CAD](https://washingtoncad.org/), linked by the county tax office, is the matching source; verify individual records and available exports.

### Sources Shared Across Counties

- **TDLR TABS:** the [project search](https://www.tdlr.texas.gov/tabs/search) exposes county and date filters; test all relevant work types, results pagination and each detail page, without guessing statewide sequential project numbers.
- **Open bids:** [College Station's bid page](https://www.cstx.gov/business-development/bid-opportunities/) links the regional marketplace; inventory each county, city and relevant school/college buyer's actual procurement route before claiming coverage of them all.
- **Additional signals:** investigate [TCEQ construction records](https://www.tceq.texas.gov/permitting/central_registry), [TABC pending applications](https://www.tabc.texas.gov/static/sites/default/files/2022-10/public-inquiry-instructions-applications.pdf) and [Comptroller business-location data](https://comptroller.texas.gov/transparency/open-data/search-datasets/); construction filters, current downloads and account requirements still need access tests.
- **Coverage control:** use official county/city directories and the [Comptroller directory](https://comptroller.texas.gov/taxes/property-tax/county-directory/index.php) to seed a complete jurisdiction checklist, then verify it against local sources; today's named sources are a starting inventory, not an exhaustive list of every municipality or buyer.

## 3. Run In Small, Checkable Batches

1. **Prepare access and coverage:** finish the jurisdiction checklist, verify existing service allowances and record the exact date range, record type and access method for each source.
2. **Prove the readers:** inspect a few real records from each source, including an empty result, multiple result pages and an error response; build source-specific tests before large downloads.
3. **Collect strong signals first:** run TABS by county, accessible local permits and current bids; collect early planning cases alongside them and keep a separate progress receipt for each source.
4. **Expand the history and geography:** backfill the proposed windows, work through smaller-town and county-administered sources, and document unavailable registers rather than getting stuck on one office.
5. **Add supporting signals:** link stormwater, new-business, occupancy and other relevant records where access is proven; a new company registration alone is not evidence of building work.
6. **Match properties:** connect permits, plans and parcels using their IDs, location, work description and dates; preserve different suites, lots and phases, and leave uncertain matches for review.
7. **Research the strongest candidates deeply:** use Jina, existing search access and business websites to check participants, business contacts, recent status, scope and evidence, in batches of ten for review; ten is a work-batch size, not the PDF's property limit.
8. **Review and freeze the result:** inspect every shortlisted profile, recheck bid deadlines/status before finalization, then prepare matching PDF, website and agent data with one report version.

Do not scrape every property owner's contact information across seven counties; investigate owners and contacts for properties supported by relevant project signals.

## 4. Keep The Run Bounded And Honest

- Reuse direct downloads, existing collectors, Jina and already-available services; no new subscriptions, datasets, credit purchases or unapproved overages.
- Before paid endpoints are used, verify allowance and billing behavior; if it cannot be verified, use no-new-charge routes or mark that source pending rather than assuming unlimited access.
- Proposed starting limits: one request at a time per website, at least two seconds between requests or the site's slower requirement, at most two retries for temporary failures, then pause that source after three consecutive failures; honor any longer server retry instruction.
- Pause immediately for login requirements, a clear access restriction, payment requirements or an unexpected document format; do not rotate tools to defeat restrictions.
- Break work into 15-30 minute tasks; a checkpoint or time limit means partial progress, never proof that all records were collected.
- Save progress after each file or results page with its original content, URL, retrieval time, record date and a content fingerprint; repeat runs on the same files must not duplicate leads.
- Confirm the county and state from the actual record, not just a search query or website name; check postal-city names and cross-county boundaries against the property location.
- Keep total downloaded records, unique projects, shortlisted properties and available contacts as separate counts; one property appearing in five sources is not five leads.
- Preserve error reasons and incomplete date ranges; a blocked page is not an empty result, and a blank application form is not an issued permit.
- If an official export needs a request, prepare the requested fields and recipient route; sending requests or creating accounts is not part of today's research and remains a scope decision.

## 5. What Comes Out Of The Run

- **Evidence archive:** original downloaded pages/documents, their dates and the exact fields extracted; raw files remain outside the public website.
- **Candidate collection:** distinct projects and properties with linked sources, owners and participants separated by role, trade matches and missing-information flags.
- **Research shortlist:** the best supported local opportunities, with clear reasons for inclusion and no guessed hiring intent, invented contact details or unsupported sales predictions.
- **Coverage report:** each source's requested versus covered dates, pages/files examined, counts, errors and status; every selected jurisdiction has either results or an explicit gap, never a silent omission.
- **Delivery package:** the fixed detailed PDF, short ranked website preview and agent-readable records using the same IDs and version; integration into the live site/agent is a later build step, not automatic from saving files.
- **Public-data review:** publish useful project facts and appropriate business contacts; exclude private notes and unnecessary personal homeowner contact details from public exports.
- Keep expired bids, confirmed completed jobs and rejected records as traceable history, not active leads; unknown stage must stay unknown.
- No fixed lead quota, recurring crawl, automatic PDF updates, prospect outreach or separate lead-note system is introduced.

## 6. How We Know It Is Ready

- Every included property has an identifiable location/project, a reason it matches Masiate, dated supporting evidence and a status label that does not overstate what is known.
- Check every final PDF entry against its sources; also review up to ten extracted records per source, including rejected and uncertain rows, so bad parsing is not hidden by plausible top results.
- Prove all requested pages/files were read before marking a source complete; if a site caps search results, split date ranges and reconcile counts or mark coverage partial.
- Distinguish source completion from geographic completeness: exhausting a city portal does not prove all work in that county was found.
- Verify one property appearing in several sources merges correctly, two different suites do not merge, revised plans update a project, and an old record does not become "new" on download day.
- Check that website, PDF and agent agree on identities, facts, dates and sources; test empty results, unavailable sources, exhausted allowances and broken documents.
- Reopening a person's saved chat must preserve their research without changing the PDF or exposing another person's history.
- This planning pass found official starting points for all seven counties, but did not test all individual records or pagination, send requests, use paid collection APIs, implement a scraper or produce the final property PDF.

### Remaining Decision: Records Held By An Office

- **A. Draft requests and continue with accessible sources:** recommended practical start; drafts stay unsent until reviewed, and the report can disclose outstanding gaps.
- **B. Include sending requests for no-charge electronic records in the later authorized run:** wait for replies before finalizing the report; the sender identity and actual records availability still need checking, and any fee quote stops that request.
- **C. Use online-accessible records only:** no request workflow; accept and disclose the missing sources.
- **D. Finish accessible collection first, then choose requests based on actual gaps:** avoids unnecessary requests but delays deciding how complete the final report can be.

This is a collection design, not a runnable build-loop plan; no workers or scheduled jobs have been started.
