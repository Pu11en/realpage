# Masiate's Request: Catch Projects Early

## What Masiate Asked For
- **Best stage:** from **site plan** (early, before contractors are picked) through **building permit** (project is really moving).
- **Fields they want:** owner/developer or company name, project address, type of project, contact info, and any scope details.
- **Still okay:** projects already under construction, but earlier is preferred.

## What We Already Have (first pass, 49 properties)
- ✅ **35 are early stage** (site plans, development reviews, state project registrations filed before building).
- ✅ **13 are at building permit stage** (permit issued, mostly Brenham/Washington County).
- **Only 1 is already under construction** (AutoZone in Navasota).
- ✅ **Owner/developer name, address, project type and scope** are filled in for all 49.
- ✅ **Contact route found for all 49** (47 solid, 2 best guesses) — but only **27 point to the owner/developer**; 12 point to an architect or engineer, 8 to a general contractor.
- So the first pass already lines up closely with what they want.

## The Gaps
- ⚠️ **12 rows lead to a designer/engineer, not the owner.** For an early relationship, Masiate should talk to the owner or developer instead.
- ⚠️ **Bryan's permit portal** needs an account, and **College Station's permit list** loads in a way our first pass couldn't read — those are the two biggest cities.
- ⚠️ **98 more Brazos County project registrations** were collected but not reviewed.
- ⚠️ There's no way yet to see when a site-plan project **moves to the permit stage**, which is the moment Masiate said matters most.

## What We Could Do Next
- ⬜ **Re-sort the list for Masiate:** site plan → permit only, owner/developer contact first, drop the under-construction one to the bottom.
- ⬜ **Swap the 12 designer contacts** for the actual owner/developer where we can find them.
- ⬜ **Add College Station's weekly new-development and permit lists**, and review the 98 extra Brazos registrations.
- ⬜ **Stage tracking:** re-check each early project so Masiate hears when it gets its building permit.
