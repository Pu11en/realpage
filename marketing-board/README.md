# CraneSignal post map

A one-page node map for where to post CraneSignal campaign videos. Each node keeps only:

- Open: `bash ./start.sh` then http://localhost:8740
- Platform or social site
- Exact place, group, subreddit, event, or community
- Minimal copy words for that place

No tabs, no strategy notes, no long explanations.

Edit the `NODES` list in `index.html` only.

Before posting to Reddit, Facebook groups, LinkedIn groups, Slack groups, or forums, check that place's current rules in the browser.
