## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Public posts only | Drew wants posting places, not DMs, private outreach, or email blasts. |
| Rank by audience fit first | The point is to find where the right people are, then decide post format and risk. |
| Separate post targets from lurk-only places | Some communities have the audience but rules make posting risky. |
| Attach a plain-English card | Drew reads Discord, so the useful output needs to show inline. |
